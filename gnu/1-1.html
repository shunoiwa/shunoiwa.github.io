    1-1. 命令の実行

    Gnuplotへ命令を渡す方法は、大きく分けてインタラクティブ実行とスクリプト実行の2つです。 短い確認ならその場で入力し、同じ図を何度も作るならファイルにまとめるのが基本です。

    インタラクティブ実行

    端末でGnuplotを起動すると、gnuplot> というプロンプトが出ます。 ここへ1行ずつ命令を書いて、すぐ結果を確認できます。 

    $ gnuplot
gnuplot> plot sin(x)

    試し描き、範囲調整、オプションの確認にはこの方法が向いています。 終了するときは exit または quit を入力します。

    スクリプト実行

    図の設定が増えてきたら、命令を .gp ファイルに保存します。 例えば sample.gp を次のように書きます。 

    set xlabel "x"
set ylabel "y"
set grid
plot sin(x) title "sin(x)" lw 2

    実行方法は2通りあります。端末から直接実行する方法と、Gnuplot起動後に読み込む方法です。 

    $ gnuplot sample.gp
    gnuplot> load "sample.gp"

    複数行に分ける

    1行が長くなると読みにくいので、行末にバックスラッシュ \ を置いて次の行へ続けられます。 

    plot sin(x) title "sin" lw 2, \
     cos(x) title "cos" lw 2

    再現性が必要な図はスクリプト化しておくと強いです。 軸範囲、出力ファイル名、線種まで全部ファイルに残るので、あとから同じ図を確実に作れます。
