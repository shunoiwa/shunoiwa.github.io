    1-4. データを読み込む

    実験値や計算結果を描くときは、テキストファイルを plot で読み込みます。 列の指定、区切り文字、コメント行の扱いを押さえると失敗が減ります。

    基本の読み込み

    空白区切りの data.txt があるとします。 

    # x y
0 0.0
1 0.8
2 0.9
3 0.1

    1列目をx、2列目をyとして描くには次のように書きます。 

    plot "data.txt" using 1:2 with points title "data"

    using は u、with は w と省略できます。

    CSVを読む

    コンマ区切りのCSVを読む場合は、区切り文字を先に指定します。 

    set datafile separator comma
plot "data.csv" using 1:2 with linespoints title "measurement"

    列の計算

    列の値をそのまま使うだけでなく、式を挟むこともできます。 列は $1, $2 のように参照します。 

    plot "data.txt" using 1:($2*1000) with lines title "mV"

    データが読めないときは、まず区切り文字と列番号を疑うと早いです。 CSVなら set datafile separator comma、タブ区切りなら set datafile separator "\t" を確認します。
