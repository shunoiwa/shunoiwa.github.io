    2-1. グラフエリア

    グラフエリアは、軸、目盛り、余白、縦横比で読みやすさが大きく変わります。 ここでは図の土台を整えるための設定を扱います。

    軸と目盛り

    set xlabel "x"
set ylabel "y"
set xrange [0:10]
set yrange [0:100]
set xtics 2
set ytics 20
set grid

    軸ラベルには物理量と単位を入れると、あとから見返したときに意味が残ります。 目盛り間隔は、細かすぎず粗すぎない値にします。

    余白を調整する

    ラベルが切れる場合や凡例と重なる場合は、余白を手動で調整します。 

    set lmargin 10
set rmargin 4
set tmargin 3
set bmargin 4

    縦横比を固定する

    円や幾何図形を正しい形で見せたい場合は、縦横比を固定します。 

    set size ratio -1
plot cos(t), sin(t)

    ratio -1 はx軸とy軸の単位長をそろえる指定です。 データの形を見たい図では便利ですが、通常の時系列や散布図では不要なこともあります。

    見た目の調整は、線や点より先にグラフエリアから決めると安定します。 図の目的に合わせて軸範囲と目盛りを先に固定しましょう。
