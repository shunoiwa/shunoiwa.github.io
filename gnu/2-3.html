    2-3. 凡例

    凡例は、複数の系列を見分けるための案内です。 Gnuplotでは凡例を key と呼び、表示位置や枠の有無を設定できます。

    凡例名を付ける

    plot "data.txt" using 1:2 with points title "measurement", \
     f(x) with lines title "fit"

    title が凡例に表示される名前です。 凡例を出したくない系列には notitle を付けます。 

    plot "data.txt" using 1:2 with points title "measurement", \
     0 with lines lc rgb "#aaaaaa" notitle

    位置を変える

    set key top right
set key bottom left
set key outside right
set key at graph 0.98,0.95

    top right のような指定は手軽です。 細かく置きたい場合は at graph x,y を使います。 graph 座標では左下が 0,0、右上が 1,1 です。

    枠と並び

    set key box
set key opaque
set key spacing 1.2
set key samplen 2

    box は枠、opaque は背景を不透明にする指定です。 図中の線と重なる場合に使うと、凡例の文字が読みやすくなります。

    凡例が図のデータを隠すなら、外側へ出すか、そもそも図中に直接ラベルを書く方が読みやすいことがあります。 凡例は必ず置くものではなく、読み手が迷わないための道具です。
