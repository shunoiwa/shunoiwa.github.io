    2-4. 補助線とテキスト

    しきい値、基準線、注釈を入れると、図から読み取ってほしい点を明確にできます。 Gnuplotでは set arrow、set label、set object を使います。

    水平線・垂直線

    最も簡単な基準線は、定数関数として描く方法です。 

    plot "data.txt" using 1:2 with points title "data", \
     1.0 with lines lc rgb "#888888" dt 2 title "threshold"

    ただし凡例に含めたくない補助線なら、set arrow の方が整理しやすいです。 

    set arrow 1 from 0,1.0 to 10,1.0 nohead \
    lc rgb "#888888" dt 2 lw 1

    注釈を置く

    set label 1 "peak" at 4.2,8.5 center
set arrow 2 from 4.2,8.2 to 4.2,7.1 head

    ラベル番号を付けておくと、あとから同じ番号で上書きできます。 消す場合は unset label 1 や unset arrow 2 を使います。

    領域を塗る

    範囲を強調したいときは矩形オブジェクトを使います。 

    set object 1 rect from 2, graph 0 to 4, graph 1 \
    fc rgb "#fff2a8" fs solid 0.35 noborder

    graph 0 から graph 1 まで指定すると、y方向いっぱいの帯になります。 fc は塗り色、fs solid は透明度付きの塗り指定です。

    補助線や注釈は、図の主役を助けるために使います。 目立たせすぎるとデータより注釈が勝つので、薄い色や破線を選ぶと収まりが良いです。
