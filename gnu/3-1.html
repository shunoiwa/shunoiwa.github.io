    3-1. 近似曲線

    Gnuplotの fit コマンドを使うと、データに合うパラメータを最小二乗法で求められます。 近似した関数は、そのままデータと一緒に描画できます。

    fitコマンドの形

    fit func "datafile" using xcol:ycol via vars
    項目意味
    func近似に使う関数
    datafile読み込むデータファイル
    usingどの列をx,yとして使うか
    viaフィットで調整する変数

    直線で近似する

    a = 1
b = 0
f(x) = a*x + b

fit f(x) "data.txt" using 1:2 via a,b
plot "data.txt" using 1:2 with points title "data", \
     f(x) with lines lw 2 title sprintf("fit: %.3f x + %.3f", a, b)

    a と b には初期値が必要です。 fit の実行後、この2つの値がデータに合うように更新されます。

    誤差列を使う

    y方向の標準偏差や測定誤差が3列目にある場合は、using 1:2:3 とします。 誤差が小さい点ほど強く重み付けされます。 

    fit f(x) "data.txt" using 1:2:3 via a,b
plot "data.txt" using 1:2:3 with yerrorbars title "data", \
     f(x) with lines title "fit"

    指数関数で近似する

    A = 1
tau = 1
c = 0
g(x) = A * exp(-x/tau) + c

fit g(x) "decay.txt" using 1:2 via A,tau,c
plot "decay.txt" using 1:2 with points title "data", \
     g(x) with lines lw 2 title "exponential fit"

    非線形フィットは初期値が悪いと収束しにくいことがあります。 だいたいの大きさを見積もってから初期値を入れると安定します。

    フィット結果は便利ですが、必ず残差やデータの範囲も確認します。 係数が出たことと、そのモデルが妥当であることは別問題です。
