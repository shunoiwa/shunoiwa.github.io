    Gnuplot備忘録

    概要

    Gnuplotで関数や実験データを図にするためのメモです。 まずはコマンドの実行方法、基本設定、関数とデータの描画を押さえ、 その後に見た目の調整や近似曲線へ進む構成にしています。

    表記のルール

    先頭に $ が付いた例は、端末やPowerShellなどで実行するコマンドを表します。 $ 自体は入力しません。 

    $ gnuplot

    コード中の斜体は置き換える値です。例えば plot func の func には、sin(x) や自分で定義した関数名を入れます。

    Gnuplotは「設定してから描く」流れで考えると迷いにくいです。 set で出力形式・軸・範囲・見た目を決め、最後に plot や splot で描画します。
